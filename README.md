## Projetos em destaque

### 01. Audi3 Tech Center

<sub>PROJETO EM DESENVOLVIMENTO · PYTHON</sub>

Uma plataforma de gerenciamento de computadores corporativos, criada para centralizar informações técnicas dos equipamentos de uma empresa.

**O que estou desenvolvendo:**

- Coleta automatizada de informações dos computadores.
- Identificação de processador, memória RAM e armazenamento.
- Consulta de sistema operacional e endereço IP.
- Associação de computadores a funcionários e setores.
- Painel web para visualização dos equipamentos.
- Atualização periódica das informações.

**Tecnologias:** Python · Flask · SQLite · HTML · CSS
